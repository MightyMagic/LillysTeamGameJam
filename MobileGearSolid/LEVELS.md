# Mobile Gear Solid — уровни, сценарии и тексты

Всё содержимое игры лежит в обычных текстовых файлах. Unity перечитывает их при каждом запуске Play.

| Что | Где |
|---|---|
| Все тексты игры (меню, HUD, подсказки, реплики) | `Assets/Resources/Texts/texts.txt` |
| Уровни (по одному файлу на миссию) | `Assets/Resources/Levels/<id>.txt` |
| Порядок миссий в меню | `Assets/Resources/Levels/campaign.txt` |
| Визуальный редактор уровней | Unity → меню **Mobile Gear Solid → Level Editor** |
| Пиксель-арт (генерируется скриптом) | `Tools/gen_art.py` → `Assets/Resources/Sprites` |

## Тексты — `texts.txt`

```
ключ = текст
```
* `\n` — перенос строки, `{0}`, `{1}` — подставляемые значения (их нельзя удалять).
* Работают теги `<color=#ff0000>…</color>`, `<b>…</b>`, `<size=24>…</size>`.
* Название/брифинг/угрозы миссии: `<id>.title`, `<id>.brief`, `<id>.threats` (id = имя файла уровня).
* Имя персонажа в диалоге: `speaker.<имя>`, портрет — спрайт `Sprites/portrait_<имя>.png`.
* Если ключ не найден, в игре будет видно `#ключ`.

## Файл уровня

```
[mission]
objectives = keycard, extract     # keycard | power | data | prototype | extract (extract всегда последний)
sides = intel:2, nokills          # nokills | noalerts | allintel | intel:N | time:СЕКУНДЫ
hp = 4                            # необязательно: здоровье, патроны, ловушки на старте
ammo = 6
decoys = 1
tutorial = false                  # true: без брифинга, поимка = откат к чекпоинту

[map]
...ASCII-карта, 1 символ = 1 клетка...

[guards]
# одна строка = один охранник: точки маршрута по порядку (символы с карты)
6 7 8 9
0 1 speed=1.3                     # speed — множитель скорости
5 look=left                       # одна точка + look = стоит на посту и смотрит в сторону (up/down/left/right/градусы)

[script]                          # необязательно, см. ниже
```

### Легенда карты

| Символ | Что | Символ | Что |
|---|---|---|---|
| `#` | стена | `.` | пол |
| ` ` (пробел) | пустота | `D` | проём/дверь |
| `L` | дверь по пропуску | `X` | выход (в стене, пол должен быть **снизу**) |
| `C` | камера (в стене, смотрит в сторону пола) | `V` | вентиляция (декор в стене) |
| `^` | лампа | `P` | старт игрока |
| `x` | **коробка, чтобы прятаться** | `K` | пропуск |
| `T` | разведданные | `R` / `M` / `W` | патроны / аптечка / ловушка |
| `E` | электрощит | `S` | терминал данных |
| `O` | прототип | `c k b u h r t w l` | ящик, коробка-декор, бочки, стеллаж, сервер, стол, оружейка, шкафчик |
| `g` / `y` | решётка / разметка на полу | `0-9 A B F G H I J N Q U Y Z` | точки маршрутов и метки для сценария |

Стены рисуются «лицом» автоматически, если под ними пол. Точки маршрутов — это обычный пол.

## Сценарий `[script]`

Команды выполняются по очереди. Команда `wait` ждёт, пока не выполнится условие.

| Команда | Что делает |
|---|---|
| `say <персонаж> <ключ>` | реплика в стиле визуальной новеллы, игра на паузе до нажатия (`say major tut.kill.1`) |
| `objective <ключ>` | заменить цель в HUD |
| `toast <ключ>` | короткое сообщение над кнопками |
| `highlight shoot \| interact \| trap \| none` | мигающая подсветка кнопки (снимается сама после следующего `wait`) |
| `checkpoint <метка>` | куда вернуть игрока, если его заметили (в обучении) |
| `wait kill [N]` | пока всего устранено ≥ N |
| `wait reach <метка> [радиус]` | пока игрок не подойдёт к метке (радиус по умолчанию 1.5) |
| `wait hide` | пока игрок не залезет в коробку |
| `wait trap` | пока игрок не поставит ловушку |
| `wait time <сек>` | просто подождать |
| `end` | успешно завершить уровень |

## Как добавить новую миссию

1. **Mobile Gear Solid → Level Editor → Новый** (или скопируй любой `.txt` в `Levels`).
2. Нарисуй карту: ЛКМ — кисть, ПКМ — пипетка. Справа видно, всё ли достижимо.
3. Впиши имя файла в `campaign.txt`, а тексты `<id>.title / .brief / .threats` — в `texts.txt`.
4. **▶ Сохранить и играть** — запустит Play сразу с этим уровнем.
